## Minor
### 🟡 Large JavaScript Bundle Size in Web Production Build, `apps/web/src/App.tsx:1`
**Problem**: The frontend production build bundles Plotly directly into the main entry bundle, generating a single minified JavaScript chunk of 4.8MB.
**Why it matters**: A large initial bundle slows down first contentful paint and page load times over mobile or slower network connections.
**Suggested fix**: When implementing the analytical dashboard views in Slice 1, use dynamic React `React.lazy()` or dynamic `import('plotly.js-dist-min')` code splitting so the charting library is loaded on demand only when visiting chart views.

### 🟡 Empty String Timestamp in Pipeline Comparison, `packages/comparison/evaluator.py:39`
**Problem**: In `PipelineComparator.compare_metrics`, the `timestamp` field on `PipelineComparisonResult` is hard coded to an empty string `""`.
**Why it matters**: Cross pipeline evaluation logs recorded without timestamps hinder auditability and chronological comparison analysis in the competition evaluation.
**Suggested fix**: Use `datetime.now(timezone.utc).isoformat()` when populating `PipelineComparisonResult.timestamp`.

### 🟡 Starlette TestClient Deprecation Warning, `tests/api/test_health.py:1`
**Problem**: Pytest outputs a single deprecation warning: `StarletteDeprecationWarning: Using httpx with starlette.testclient is deprecated; install httpx2 instead`.
**Why it matters**: Future updates to Starlette or FastAPI may drop support for legacy test client invocation.
**Suggested fix**: Pin compatible `httpx` or update testing fixtures when upgrading FastAPI in future dependencies pass.
